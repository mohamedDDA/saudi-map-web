# خريطة المملكة — نسخة الويب (تعمل دون إنترنت)

1. ارفع كل الملفات إلى مستودع GitHub (الجذر).
2. Settings ← Pages ← Source: **GitHub Actions**.
3. Settings ← Actions ← General ← Workflow permissions: **Read and write**.
4. Actions ← "Build offline data" ← Run workflow (يبني بيانات البحث والطرق، ثم ينشر الموقع تلقائياً).
5. افتح الموقع، ثم الأدوات ← "تنزيل / تحديث البيانات" (واي فاي).
